Cyber Attack Dataset Analytics

An Advanced Information Security semester project exploring a 40,000-record cybersecurity dataset through statistical analysis, visualization, Random Forest classification, dense neural networks, and a 1D convolutional neural network.

View Existing Project Files All Projects

Objective

Explore cybersecurity-event characteristics and implement multiple classification approaches for comparative analysis.

Dataset

40,000 records across 25 fields, including network, traffic, attack, severity, device, firewall, and IDS/IPS information.

Implemented Models

Random Forest, a dense neural network, and a 1D-CNN with evaluation, timing, and comparison routines.

Project Workflow

  1. LoadRead the cybersecurity attack dataset into pandas for inspection and analysis.
  2. PrepareDrop missing records, encode categorical values, select features, and standardize model inputs.
  3. SplitCreate reproducible 70% training and 30% testing subsets using a fixed random state.
  4. ModelImplement Random Forest, dense neural-network, and 1D-CNN classification workflows.
  5. EvaluateGenerate accuracy, classification reports, confusion matrices, timing, and model-comparison output.
  6. VisualizeAnalyze feature importance, time, ports, browsers, operating systems, and training history.

Implemented Analysis

  • Random Forest feature importance
  • Confusion-matrix visualization
  • Attack activity by hour and day
  • Source-port and traffic-type heatmaps
  • Browser and operating-system distributions
  • CNN training and validation history

Project Boundaries

  • The repository preserves the original course-project scripts.
  • Some scripts contain hard-coded local dataset paths.
  • Later feature selections require alignment with the included CSV schema.
  • No saved execution output is available, so no model score is claimed.
