Amazon Co-Purchase Recommendation System

Big Data Analysis and Security (CSEC 5311)

A CSEC 5311 semester project that transforms Amazon co-purchasing relationships into implicit interactions, trains a PySpark ALS collaborative-filtering model, and presents recommendation output through Python visualizations, Power BI, and the Spark Web UI.

View Project Repository All Projects

Objective

Build a scalable recommendation pipeline from Amazon product metadata and co-purchase relationships.

Model

PySpark Alternating Least Squares collaborative filtering using implicit interactions.

Recorded Result

RMSE of 0.3904 on the original 20% held-out test set.

Established Project Workflow

  1. ParseExtract ASIN, title, product group, and similar-product relationships from the semi-structured Amazon metadata.
  2. TransformMap ASIN values to integers and represent co-purchase links as implicit interactions with a rating of 1.0.
  3. SplitCreate an 80% training and 20% testing split for the evaluated implementation.
  4. TrainFit a PySpark ALS model with 10 iterations, regularization of 0.1, and cold-start handling.
  5. EvaluateCalculate RMSE on held-out predictions and preserve the recorded score of 0.3904.
  6. PresentExport 100 recommendation rows and analyze them with Matplotlib, Seaborn, Power BI, and Spark Web UI.

Implemented Analysis

  • Amazon metadata parsing with regular expressions
  • ASIN-to-integer identifier mapping
  • Implicit co-purchase interaction matrix
  • Top-ten recommendations for ten users
  • Top recommended-products bar chart
  • User-item prediction heatmap
  • Interactive Power BI dashboard
  • Spark jobs, stages, storage, environment, executors, and SQL monitoring

Project Boundaries

  • The source code and outputs remain in their original course-project state.
  • The scripts use the original WSL paths and require the SNAP Amazon metadata file.
  • The RMSE is transcribed from the submitted report, not a newly reproduced benchmark.
  • The uploaded Power BI artifact confirms the submitted dashboard work.
